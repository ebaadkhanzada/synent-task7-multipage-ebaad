# Synent Task 7: Multi-Page Corporate Website

## Objective
To design and develop a responsive multi-page web platform (Home, About Us, Services, Contact) featuring a cohesive design system, easy navigation, and mobile layout support.

## Steps Performed
1. Architected the portal structure across four primary sections: Home, About Us, Services, and Contact.
2. Formatted styling using CSS Grid and Flexbox for grid alignments, cards, and adaptive typography.
3. Created an accessible top navigation bar with an automated hamburger drawer menu for mobile screens.
4. Built smooth client-side view switching and interactive contact form validation handling using JavaScript.
5. Validated UI layout consistency across high-resolution displays, laptops, and smartphones.

## Tools Used
- **Languages:** HTML5, CSS3, Modern JavaScript (ES6+)
- **Design & Layout:** CSS Flexbox, CSS Grid, Media Queries
- **Development Environment:** Visual Studio Code
- **Version Control:** Git, GitHub

## Outcome in Brief
A clean, professional, cross-browser compatible corporate web application featuring unified styling, responsive navigation, and interactive user inputs.
